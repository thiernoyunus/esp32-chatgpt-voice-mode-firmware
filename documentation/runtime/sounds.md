# Sounds

UI sound effects live in `main/assets/common/` as Ogg/Opus: mono 16 kHz, 48 kbps, 60 ms frames, peak-normalized to -20 dBFS — effects, not protagonists.

## Pitch variants

The frequent effects (`mode_switch`, `listen_start`, `listen_end`, `speech_done`) have `_v2`/`_v3` siblings pitch-shifted about a semitone down/up with duration preserved. `main/assets/sound_variants.h` picks one at random per play, so a repeated effect never sounds machine-identical. Alert sounds (`exclamation`, `low_battery`) stay single-version on purpose: alarms should be instantly recognizable.

## Converting new sounds

```sh
./scripts/convert_apollo_sounds.sh <mp3-dir>
```

The script normalizes, encodes, and generates the variants for every known effect it finds in the directory.

## The regeneration trap

`lang_config.h` (the header with the `Lang::Sounds::OGG_*` symbols) is generated by a CMake rule that depends only on `language.json` — **not** on the sound files. After adding a new `.ogg`:

```sh
python3 scripts/gen_lang.py --language es-ES --output main/assets/lang_config.h
touch main/CMakeLists.txt   # the asset glob runs at configure time
```

Skip this and the build succeeds against the stale header — or fails on the missing symbol while flashing the previous binary (the build script exits 0 on failure; see [Build](../operations/build.md)).
