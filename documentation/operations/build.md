# Build

```sh
python scripts/build.py waveshare/esp32-s3-touch-lcd-1.85c
```

The manufacturer prefix is required. Only this board builds in this fork; the board and language menus in Kconfig were trimmed to the single supported option each (es-ES with en-US fallback).

## Traps

- **The build script exits 0 on failure.** It prints `[ERROR]`, and ninja prints `FAILED:`, but the exit code stays 0 — grep the output, or a flash afterward will happily write the *previous* binary. An identical "compressed size" in esptool's output is the tell.
- New `.ogg` assets need the language header regenerated by hand; see [Sounds](../runtime/sounds.md).

## Output

A successful build produces `build/merged-binary.bin` plus the individual images (`xiaozhi.bin`, `expression_assets.bin`, bootloader, partition table) and `build/flash_args` for esptool.
